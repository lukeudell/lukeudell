### Engineering Values

I maintain a [500-line engineering standards document](https://lukeudell.com/standards/) that governs everything I build. The short version:

- **Pin dependencies. Test everything. Zero-CVE tolerance.** Boring discipline is how you ship things that last.
- **Documentation is infrastructure.** If the next person can't pick it up from the README, it isn't finished.
- **Segment before you scale.** Clean boundaries now save rewrites later.
